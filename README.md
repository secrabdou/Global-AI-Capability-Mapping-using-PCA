# 🌍 Global AI Capability Mapping using PCA

An unsupervised machine learning project that analyzes the global landscape of Artificial Intelligence development. Using **Principal Component Analysis (PCA)**, this project compresses **7 multi-dimensional pillars of AI capability** down into a 2D space to uncover distinct national clusters and structural differences in how countries approach AI implementation.

---

## 📊 Project Overview & Core Concept
When dealing with complex country profiles, analyzing 7 distinct metrics simultaneously makes it difficult to visually identify trends. 

Instead of neglecting features or throwing away valuable data, this project uses **PCA** to blend the variables together into two master axes: **PC1** and **PC2**. This process reduces the dimensionality of the dataset from 7D to 2D while retaining the vast majority of the original information (variance), making it easy to plot and interpret on a flat screen.

### The 7 Pillars of AI Analyzed:
1. **Talent:** Availability of skilled AI practitioners.
2. **Infrastructure:** Compute power, data centers, and access.
3. **Operating Environment:** Regulatory frameworks and public opinion.
4. **Research:** Academic publications and citations.
5. **Development:** Open-source contributions and commercial platforms.
6. **Government Strategy:** National spending commitments and policy.
7. **Commercial:** Private investment and startup ecosystem activity.

## 🛠️ Data Pipeline & Technical Steps

The workflow follows a standard, production-ready data science pipeline:

1. **Targeted Data Cleansing:** Used `dropna(subset=features)` to isolate rows with high data integrity across our core AI pillars without unnecessarily dropping entries missing non-essential metadata.
2. **Feature Standardization:** Applied `StandardScaler` to normalize the scales. Because metrics range from granular scores to massive percentage differences, scaling ensures PCA treats each pillar with equal weight rather than favoring attributes with naturally larger absolute values.
3. **Dimensionality Reduction:** Fit `sklearn.decomposition.PCA` to transform the 7-dimensional standardized matrix into 2 orthogonal Principal Components.
